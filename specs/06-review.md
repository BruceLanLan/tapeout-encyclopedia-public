# Human review checklist

Use this before merging to `published`.

## Content

- [ ] Summary is accurate and non-promissory
- [ ] Definition matches cited sources
- [ ] Boundaries / non-claims section present for wallet or money topics
- [ ] Official vs community status correct
- [ ] No stale numeric “current” claims without `data_refs`

## Graph

- [ ] Entity id stable and unique
- [ ] Relations have confidence + sources
- [ ] No orphan edges

## i18n

- [ ] Slug parity with other locales when they exist
- [ ] Glossary terms respected

## Process

- [ ] Agent drafts reviewed by a human
- [ ] Contributor credited in PR (and translators list if applicable)
