# Source tiers

Every claim needs a tier. Higher tiers win when sources conflict; lower tiers must not be presented as official.

| Tier | Meaning | Examples |
| --- | --- | --- |
| `official` | Protocol / founder / official site materials | tapeout.net pages, official contracts docs |
| `community-reviewed-guide` | Independently proofread community textbook | chickdady-svg beginner guide |
| `observed-data` | Independently observed, method disclosed | tapeout.work APIs & methodology notes |
| `community` | Community tools, posts, indexes | ecosystem directories, Dune dashboards |
| `unverified` | Single source, not yet reviewed | social posts, hearsay |
| `deprecated` | Known outdated; keep for history | old task lists after rule changes |

## Writing rules

1. Mark official status only with `official` sources.
2. Cite the beginner guide for pedagogy and definitions when it covers the topic.
3. For live counts (processors, circuits, prices), prefer `observed-data` links over copying numbers into Markdown.
4. Never upgrade a `community` tool to `official` without an official source.
5. Investment / yield language is out of scope unless quoting a public formula with a risk boundary.
