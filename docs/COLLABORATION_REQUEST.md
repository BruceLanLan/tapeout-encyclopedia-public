3. 如你愿意，也欢迎你成为百科仓库的 reviewer / collaborator。

## 为什么要新建百科，而不是直接在本仓库扩写

本仓库 [`CONTRIBUTING.md`](https://github.com/chickdady-svg/tapeout-beginner-guide/blob/main/CONTRIBUTING.md) 已经写得很清楚：

- 不要翻译或扩写原文没有的内容；
- 只修正有原 PDF 依据的问题；
- 合并前需人工对照原 PDF 复核。

这些规则对「稳定教材」是正确的。但 TapeOut 还需要另一层能力：

- 持续新增词条（工具、事件、协议变更、术语对照）；
- 中英及其他语言的对等投稿；
- 机器可读的知识图谱（实体 / 关系）；
- 让人类与 AI Agent 按统一 schema 共建，而不是改 PDF 正文。

若把这些塞进本仓库，会破坏你已经建立的溯源与校对契约。因此我们选择 **A：新建姊妹仓库做百科 + 图谱**，本仓库继续专注新手指南。

更完整的说明见百科仓库文档：`docs/WHY_NEW_REPO.md`（百科仓库 URL 上线后补上）。

## 我们如何引用本仓库

百科会把本指南标为高信任来源，并尽量链回具体章节与 `source` 页码注释；**不会**在本仓库内扩写或改写教材契约。观测数据继续走 tapeout.work 的公开 API，与教材正文分离。

若你同意协作，我可以按你的习惯先开一个小的维护型 PR（例如死链检查），证明我们遵守 CONTRIBUTING。
